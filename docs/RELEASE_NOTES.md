Lock In keeps track of your chosen study apps and windows, and reminds you when you drift away.

- macOS: native SwiftUI menu bar app, browser URL matching, focus dashboard, reminders, and history.
- Windows beta: native tray app, process/window-title matching, reminders, breaks, local history, and interrupted-session recovery. Browser matching uses title keywords rather than URLs. The Windows UI and ARM64 build need feedback from real Windows devices.
- Local data only. No accounts, analytics, or subscriptions.

Download the ZIP for your platform, extract it, and follow the [installation guide](https://github.com/saiompatro/lock_in#installation). The macOS app is ad-hoc signed and not notarized; Windows executables are unsigned. OS security prompts are expected. SHA-256 checksums are included in `SHA256SUMS.txt`.

The macOS archive supports Apple Silicon and Intel on macOS 14+. Windows archives include .NET and support x64 or ARM64 respectively.
