# Security and privacy reports

Please report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/saiompatro/lock_in/security/advisories/new) if it is enabled for this repository. If unavailable, open an issue requesting a private contact method without posting exploit details or personal data.

Include the affected version, operating system, impact, and minimal reproduction steps using synthetic data. Do not attach your real study spaces or history.

Security fixes target the latest release. Lock In has no server or accounts. All app data is local; anyone with access to your OS account may be able to read it. Distribution archives currently use ad-hoc macOS signing and unsigned Windows executables. Review the release notes and checksums before installation.
